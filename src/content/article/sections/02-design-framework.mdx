## 设计思路

围绕增长运营产品，可以将五要素重构为以下设计框架：

| 层级 | 模块一 | 模块二 |
| --- | --- | --- |
| 战略层 | 增长目标：目标用户、目标行为、激励预算 | 用户动机 |
| 范围层 | 玩法内核：玩法奖励、玩法机制 | 玩法包装 |
| 结构层 | 系统架构 | 玩法流程：核心流程、新手流程 |
| 框架层 | 主页框架：页面布局、页面层级 |  |
| 表现层 | 感知设计：场景的情感化、行为引导、行为反馈 |  |
